# Loop Skills Specification

## Purpose

Skill definitions for Claude Code and OpenCode that wrap the ILO CLI commands, enabling agents to invoke the implementation loop through natural slash commands.

## ADDED Requirements

### Requirement: Claude Code skill generation

The system SHALL generate Claude Code skill files in `.claude/skills/` that wrap the ILO CLI commands. Each skill MUST include a `SKILL.md` file with the skill name, description, and instructions for the agent.

#### Scenario: Generated skills

- **WHEN** the user runs `sdf skills generate --tool claude`
- **THEN** the system SHALL create:
  - `.claude/skills/sdf-run/SKILL.md` — wraps `sdf ilo run`
  - `.claude/skills/sdf-status/SKILL.md` — wraps `sdf ilo status`
  - `.claude/skills/sdf-check/SKILL.md` — wraps `sdf ilo check`
  - `.claude/skills/sdf-plan/SKILL.md` — wraps `sdf ilo plan`
  - `.claude/skills/sdf-graph/SKILL.md` — wraps `sdf graph build`
  - `.claude/skills/sdf-impact/SKILL.md` — wraps `sdf graph impact`

### Requirement: OpenCode skill generation

The system SHALL generate OpenCode skill files in `.opencode/skills/` or the appropriate OpenCode configuration directory.

#### Scenario: Generated OpenCode skills

- **WHEN** the user runs `sdf skills generate --tool opencode`
- **THEN** the system SHALL create skill files equivalent to the Claude Code skills but formatted for OpenCode's skill system

### Requirement: Skill instruction content

Each generated skill MUST include instructions that tell the agent: what the command does, when to use it, how to interpret the output, and what follow-up actions to take. The instructions MUST NOT require the agent to have prior knowledge of the ILO.

#### Scenario: Run skill instructions

- **WHEN** the agent reads `.claude/skills/sdf-run/SKILL.md`
- **THEN** the instructions SHALL explain: "This runs the implementation loop. It will check artifact completeness, identify gaps, and produce an execution plan. If artifacts are missing, it will output generation requests that you should fulfill."

### Requirement: Skill update on CLI changes

The system SHALL regenerate skill files when `sdf skills generate` is re-run, overwriting existing skill files. It MUST NOT modify skill files that were not generated by the system (user-created skills).

#### Scenario: Regeneration safety

- **WHEN** the user has a custom `.claude/skills/my-custom/SKILL.md` and runs `sdf skills generate --tool claude`
- **THEN** only `sdf-*` skill directories SHALL be modified; `my-custom` SHALL be untouched
